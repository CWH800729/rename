# 照片批次更名工具

以繁體中文操作的 HTML 照片批次重新命名工具。可在電腦瀏覽器開啟，支援縮圖預覽、個別及批次編輯、ZIP 下載，以及授權後寫回原資料夾。廠商與工項的常用選項透過 Google Sheet 共用管理。

照片內容在本機處理，不會傳送至 Google Sheet 或 Apps Script。共用清單功能需要網路；照片預覽、更名及 ZIP 產生不依賴 Google Sheet 連線。

## 功能

- 拖曳照片、選擇多張照片，或讀取包含子資料夾的資料夾。
- 左側縮圖、右側日期／廠商／工項及簡易內容欄位；點縮圖可放大。
- 勾選不連續照片，或點照片編號搭配 Ctrl／⌘ 加選、Shift 範圍選取。
- 以編號輸入範圍，例如 `1-10,12`。
- 只批次修改指定欄位，其他欄位及未選中的照片保持原值。
- 廠商與工項可留白，亦可輸入關鍵字即時篩選常用選項，點選或用方向鍵、Enter 填入。
- 「清單」視窗可新增、修改、刪除常用選項；支援 Google Sheet 共用或瀏覽器本機儲存。
- 輸出前預覽檔名，重複檔名自動加流水號，保留原副檔名及照片內容。
- 支援 ZIP 下載；支援的瀏覽器可授權寫回來源資料夾。

## 開始使用

1. 下載 `index.html` 並用電腦瀏覽器開啟，或開啟已部署的靜態網站。
2. 匯入照片。若希望寫回來源資料夾，請使用「授權原資料夾（可寫回）」。
3. 填寫每張照片的日期、廠商與工項及簡易內容。日期必填，其餘兩欄選填。
4. 如需批次修改，先選照片，再勾選要修改的欄位、填入內容，按「套用至選中照片」。勾選後留白可清空該欄。
5. 選擇輸出全部照片或僅選中照片，按「確認檔名及輸出」。
6. 檢查新檔名後，選擇下載 ZIP 或寫回原資料夾。

日期預設使用檔案最後修改日，並非相機 EXIF 拍攝日期，請依實際紀錄調整。

## 命名規則

```text
YYYYMMDD-廠商-工項及簡易內容.原副檔名
```

| 輸入情況 | 輸出範例 |
| --- | --- |
| 所有欄位均填寫 | `20261102-TSMC-3F鋼筋查驗.JPG` |
| 廠商留白 | `20261102-3F鋼筋查驗.JPG` |
| 工項及簡易內容留白 | `20261102-TSMC.JPG` |
| 廠商、工項及簡易內容均留白 | `20261102.JPG` |
| 檔名重複 | `20261102-TSMC-3F鋼筋查驗-001.JPG` |

- 日期可輸入 `20261102` 或 `2026/11/02`，檔名統一使用 8 位日期。
- 空白欄位及其分隔線會自動略過。
- 不合法的檔名字元轉為底線。
- 檔名長度上限為 180 個 JavaScript 字串字元，過長時會提示縮短。
- 資料夾匯入的照片輸出至同一層，不保留原子資料夾結構。

## 寫回資料夾與原檔處理

寫回功能需要瀏覽器支援 File System Access API，並取得使用者授權。寫回按鈕只適用於本次輸出的照片皆由同一個「授權原資料夾」匯入時。

「寫回成功並驗證內容後，刪除這次輸出的原始照片」**預設勾選**。程式會先寫入全部新檔，逐檔比較內容，成功後才刪除對應原檔。若希望保留原始照片，請取消勾選。

此流程採複製後刪除，並非原子更名。中途中斷可能留下部分新檔；畫面會回報完成寫入及已刪除原檔的數量。完成真正更名後，請重新匯入再操作。

ZIP 下載不會修改或刪除原始照片。ZIP 不會重新壓縮照片內容，單次上限為 2 GB／65,535 張，實際處理能力仍受可用記憶體限制。

「開啟目前資料夾」會在系統資料夾選擇視窗定位已授權的資料夾，僅供瀏覽，不更換照片來源；純 HTML 無法直接啟動檔案總管或取得完整本機路徑。

## Google Sheet 共用清單

目前 `index.html` 已設定預設 Apps Script 服務網址，開啟時會嘗試讀取共用清單。瀏覽器先前另存的連線設定會優先於預設網址。

共用試算表使用「照片更名清單」工作表：

| 欄位 | 內容 |
| --- | --- |
| A1 | 廠商 |
| B1 | 工項及簡易內容 |
| A2 起 | 每格一個廠商 |
| B2 起 | 每格一個工項或常用描述 |

兩欄各自獨立，同行不代表廠商與工項的配對關係。

### 使用清單

1. 按「清單」，編輯兩欄文字，每行一個選項。
2. 按「儲存清單」，等待收到完成回報。
3. 其他使用者按「重新讀取清單」或重新開啟網頁，即可取得更新；目前沒有即時推播。

儲存時會去除空白行、前後空白及重複選項。自行輸入照片欄位的內容不會自動加入清單。每類清單最多 2,000 項，每項最多 160 字元。

共用模式下的儲存會更新整份清單，包括移除已刪除的選項。程式使用版本檢查及程式鎖，避免網站使用者以舊資料覆蓋他人修改。若發生版本衝突，先複製尚未儲存的文字，再重新讀取、合併後儲存。程式鎖不會阻止在 Google Sheet 上的人工編輯，請避免與網站儲存同時操作。

持有服務網址的人皆可讀寫這份清單；試算表本身不必公開。清單僅適合放置可共用的廠商與工項名稱。

### 部署自己的清單服務

1. 開啟 Google Sheet →「擴充功能 → Apps Script」。
2. 貼上 `Code.gs`，儲存並執行一次 `setup`，完成授權。
3. 選「部署 → 新增部署作業 → 網頁應用程式」。
4. 執行身分選「我」，存取權選「所有人」，取得 `/exec` 網址。
5. 在網站的「清單 → Google Sheet 連線設定」貼上網址，按「連接並讀取共用清單」。

若要讓其他使用者不必逐一設定，將 `index.html` 中的 `DEFAULT_CATALOG_API_URL` 設為自己的 `/exec` 網址，再分發 HTML。

更新 Apps Script 後，需從「管理部署作業」選擇新版本並部署；只儲存程式不會更新既有 `/exec` 部署。

完整步驟請見 [Google Sheet 設定說明](Google-Sheet-setup.md)。

## 瀏覽器與資料保存

- 資料夾寫回功能受瀏覽器與安全環境限制；若不支援，請改用 ZIP 下載。
- HEIC 等格式是否能顯示縮圖取決於瀏覽器；無法預覽的照片仍可更名輸出。
- 未輸出的照片欄位編輯不會在重新整理後保留。
- 本機清單及連線設定使用瀏覽器儲存空間；更換瀏覽器、清除網站資料或變更本機檔案位置後，可能需要重新設定。
- Google Sheet 讀取失敗時，仍可手動填寫照片欄位並輸出；若要使用本機清單，可在連線設定中切換。

## 常見問題

**已更新清單，其他使用者卻沒有看到？**  
請按「重新讀取清單」或重新開啟網頁，並確認使用相同的 Apps Script 網址。

**清單無法讀取？**  
確認網址以 `/exec` 結尾、已執行 `setup`，且部署存取權為「所有人」。若組織政策不允許匿名存取，需另行調整登入架構。可直接開啟服務網址並加上 `?action=list`，檢查是否回傳 `ok: true`。

**儲存結果未確認？**  
先重新讀取，核對實際清單，避免直接重送。網路中斷或完成回報暫存失效時，寫入可能已完成。

**下載 ZIP 後原檔名沒有變？**  
ZIP 只提供重新命名的副本。若需更動原資料夾，請使用授權匯入及寫回功能。
